# Electronic 1.1.3

> 个人 AI 助手 · 即时通讯 · 桌面应用

---

## 关于此版本

### 完善自动更新体验，新增界面密度设置与联系人预览，并修复启动卡死等稳定性问题

---

## 新功能

- **自动检查更新开关**：设置中新增开关（默认关闭），开启后每次启动静默检查一次新版本，失败不提示
- **更新检查与下载**：支持绕过缓存强制检查，展示新版本号与更新说明；打包环境可直接下载并安装，开发环境跳转 Release 页面
- **界面密度设置**：紧凑 / 标准两档，通过 CSS 变量全局生效（替换原「好友列表密度」，旧配置自动迁移）
- **联系人预览卡片**：点击联系人查看头像、网络来源（公网/内网）、在线状态、角色、职称、学科、邮箱与签名，并可直接发起聊天
- **会话列表删除**：支持从会话列表中移除单个会话
- **云模型列表获取**：新增 IPC 接口，从厂商 OpenAI 兼容的 `/models` 接口拉取可用模型

## 优化

- 新增 `apiFetch` 请求工具，统一自动携带 JWT 认证头
- 重构服务端地址解析（公网 / 内网），默认端口调整为 3001
- 主进程 Axios 默认携带认证 Token
- 优化聊天与设置页面布局及整体样式

## Bug 修复

- 修复启动时卡在加载页的问题（`useChatRoom.js` 开头重复的 UTF-8 BOM 导致 Vite 未重写 `vue` 导入）
- 修复多网络源（公网 / 内网）下会话键冲突的问题
- 修复 WebSocket 重连竞态（旧连接事件覆盖新连接状态）
- 更新检查改用 Electron 网络栈，复用系统证书与代理，避免证书校验失败；新增 3 次重试与更明确的错误提示
- 修复检查更新失败时向界面推送无意义提示的问题，连续失败仅记录日志
